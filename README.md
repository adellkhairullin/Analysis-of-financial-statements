# Analysis-of-financial-statements
Базовый математический анализ параметров финансовой отчетности компаний РФ из датасета https://github.com/irlcode/RFSD
Ссылка на репозиторий: https://github.com/adellkhairullin/Analysis-of-financial-statements. Разработка велась в Google Colab.
В настоящей работе были проведены следующие шаги:
1. Скачены необходимые данные для анализа датасета https://github.com/irlcode/RFSD (датасет финансовой отчетности компаний РФ). Для анализа были взяты только 1000 строк датасета и 20 столбцов:
    "inn",
    "ogrn",
    "line_1600",
    "line_1700",
    "line_1300",
    "line_1400",
    "line_2110",
    "line_2400",
    "line_1230",
    "line_1150",
    "line_1200",
    "line_1250",
    "line_1510",
    "line_1520",
    "line_2100",
    "line_2200",
    "line_2300",
    "line_1370",
    "eligible",
    "financial",
2.  Далее была выведена базовая описательная статистика данных.
3.  Далее были построены гистограммы для трех колонок (line_2100", "line_2200", "line_2400"), которые, содержат полезную информацию на мой взгляд. Было определено, есть ли в этих колонках выбросы и аномалии (значения, которые сильно отличаются от остальных значений или кажутся странными/некорректными).
4. Далее была вычислена и визуализирована матрица корреляции между всеми 20 параметрами и определены параметры с высокой корреляцией r>0.7 и r>0.9. Сформированы выводы по корреляциям с r>0.9.
5. Далее была построена диаграмма рассеивания (scatter plot) между коррелирующими колонками.
6. Сформированы выводы по данным датасета, специфике компаний из датасета и корреляции данных.
